# User guides (PDF)

- `../Piron-Work-User-Guide.pdf`: part 1, for everyone (the whole app).
- `../Piron-Work-Space-Owner-Guide.pdf`: part 2, for the owner only (Piron Work Space).

The HTML files here are the sources. After the app changes, edit the HTML and print again:

```
msedge --headless=new --disable-gpu --no-pdf-header-footer --print-to-pdf=OUT.pdf file:///PATH/piron-work-user-guide.html
```

Keep the section lists in the HTML in step with the app (new tabs, new Space sections, new switches).
